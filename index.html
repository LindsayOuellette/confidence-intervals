Catching the true average

Definition

A confidence interval is a range of values, built from our sample, that probably contains the true value we're trying to estimate.

What does 95% mean?

"I am 95% confident that the true value lies between low and high."

If we repeated the study 100 times, about 95 of those intervals would catch the true value.

A sample average will almost never be exactly right. A confidence interval is a net: a range that is very likely to catch the true value.

CIs and the t-test

The zero rule

In a t-test, the CI is for the difference between the two group means. Zero means "no difference." So ask one question: is 0 inside the net?

5.5

This always agrees with the p-value: 0 outside the 95% CI ⇔ p < .05.

Effect size

Cohen's d: how big is the difference?

The p-value tells you if there's a difference. Cohen's d tells you how big it is, in standard deviations.

Students in silence recalled slightly more words (M = 16.1, SD = 3.4) than students with music (M = 14.2, SD = 3.6), but the difference was not statistically significant, t(48) = 1.92, p = .061, 95% CI [−0.09, 3.89], d = 0.54.

  • But d = 0.54 is medium. The effect might be real, and the study may just be too small to tell.
  • A bigger sample would give a narrower net and a clearer answer.
Recap

Four things to remember

1. A CI is a net

A range of believable values for the true average (or true difference).

2. 95% is about the method

About 95 of 100 nets catch the truth. Say: "We are 95% confident…"

3. The zero rule

0 inside the CI for a difference → not significant. 0 outside → significant.

4. d = how big

0.2 small, 0.5 medium, 0.8 large. Significant doesn't always mean big.

Confidence Intervals
Research Design · Stats

Catching the true value

Definition

A confidence interval is a range of values, built from our sample, that probably contains the true value we're trying to estimate.

What does 95% mean?

"I am 95% confident that the true value lies between low and high."

If we repeated the study 100 times, about 95 of those intervals would catch the true value.

The problem

A spear or a net?

We want to know a true value: the average exam score for every student at the university. We only tested 25 students. Their average was 72.

The spear: one number

"The true value is 72."

Did it hit?

The net: a range of values

"The true value is somewhere from 67 to 77."

Did it catch it?

One number from a sample will almost never be exactly right. A confidence interval is a net: a range of values that is very likely to catch the true value.

Using a CI

The zero rule

Sometimes the true value we want is a difference. For example: how many more points do students score after tutoring? Here, 0 means "no difference." So ask one question: is 0 inside the net?

Recap

Three things to remember

1. A CI is a net

A range of values that probably contains the true value.

2. 95% = how often the net works

If we did the study 100 times, about 95 of the nets would catch the true value. Say: "I am 95% confident the true value lies between ___ and ___."

3. The zero rule

For a difference: 0 inside the CI → no real difference. 0 outside → a real difference.
